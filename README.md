# 축제 부스 줄서기 (방문자 / 부스 운영자 / 전광판)

세 앱이 같은 Firebase 데이터를 함께 봐요.

| 파일 | 누가 쓰나 | 하는 일 |
|---|---|---|
| visitor.html | 방문자 (폰) | 부스 대기현황(목록·지도), 줄서기, 내 번호표, 호출 알림 |
| booth.html | 부스 운영자 / 총괄 | 호출, 입장 완료, 현장 접수, 접수 중지, 부스 설정, 부스 QR |
| board.html | 전광판 (TV·모니터) | 전체 부스 대기 시간 크게 보기 + 줄서기 QR |
| index.html | 운영진 | 세 화면으로 가는 링크 모음 |
| config.js | 설정 | Firebase 값, 총괄 PIN |
| shared.js, shared.css | 공통 | 세 앱이 함께 쓰는 코드와 스타일 |
| database.rules.json | Firebase | 데이터베이스 규칙 (아래 3단계에서 붙여 넣기) |

## 먼저 써 보기 (데모 모드)
config.js의 `firebase`가 `null`인 채로 열면 데모 모드예요. 같은 브라우저의 탭 여러 개에서 세 화면을 열어 흐름을 볼 수 있어요. (다른 기기와는 연결되지 않아요.)
파일을 더블클릭하는 것보다, 이 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`으로 여는 쪽이 안전해요.
데모 PIN: 부스 `1111`, 총괄 `0000`.

## 실제 행사용 설정 (한 번만)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 구글 계정으로 로그인 → "프로젝트 추가"
2. 애널리틱스는 꺼도 돼요.
3. 왼쪽 메뉴 "빌드" → "Realtime Database" → "데이터베이스 만들기" → 위치는 싱가포르(asia-southeast1) 추천 → "잠금 모드"로 시작

### 2. 웹 앱 등록하고 설정값 복사
1. 프로젝트 개요 화면의 `</>`(웹) 아이콘 → 앱 닉네임 입력 → "앱 등록" (호스팅은 체크 안 해도 돼요)
2. 화면에 나오는 `firebaseConfig`의 값들을 config.js의 `firebase: { ... }` 안에 붙여 넣어요.
   `databaseURL`이 빠져 있으면 Realtime Database 화면 맨 위의 주소를 복사해서 넣어요.

### 3. 규칙 붙여 넣기
Realtime Database → "규칙" 탭에 database.rules.json 내용을 통째로 붙여 넣고 "게시"를 눌러요.

### 4. 총괄 PIN 바꾸기
config.js의 `masterPin`을 바꿔 주세요. 기본값 0000은 누구나 짐작할 수 있어요.

### 5. 인터넷에 올리기 (둘 중 하나)
- **Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓으면 주소가 나와요.
- **GitHub Pages**: 새 저장소에 파일을 올리고 Settings → Pages에서 켜요.
이 폴더의 파일을 한꺼번에 올려야 해요. (visitor.html만 올리면 안 돼요.)

### 6. 행사 당일
1. 총괄이 booth.html에서 "총괄 모드"로 들어가 부스를 추가하고 부스별 PIN을 정한 뒤, 지도 위치를 찍어요.
2. 각 부스 운영자는 booth.html에서 자기 부스와 PIN으로 로그인해요.
3. 전광판 화면에 board.html을 띄우고 전체화면(F11)으로 둬요. 화면 구석의 QR이 visitor.html로 연결돼요.
4. 방문자는 QR 또는 visitor.html 주소로 들어와 줄을 서요. 부스 운영 화면의 "부스 QR"을 뽑아 부스 앞에 붙이면 그 부스로 바로 열려요.

## 알아 둘 점
- **보안은 장난 방지 수준**이에요. PIN 확인이 브라우저 안에서 이뤄지고, 데이터베이스 규칙도 누구나 쓸 수 있게 열려 있어요. 하루짜리 학교 행사에는 충분하지만 개인정보를 받지는 마세요. (앱은 별명과 인원만 받아요.)
- 운영자 화면 주소(booth.html)는 방문자에게 알리지 마세요.
- 방문자 한 명이 동시에 줄 설 수 있는 부스 수는 config.js의 `maxActivePerVisitor`로 정해요.
- 소리 알림은 폰이 켜져 있고 이 페이지가 열려 있을 때만 울려요. 화면이 꺼지면 알림이 안 와서, 안내문에 "화면을 켜 두세요"라고 적어 두는 게 좋아요.
- Firebase 무료 요금제로 수백 명 규모 행사는 충분해요.
